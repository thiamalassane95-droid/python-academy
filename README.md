# Akeneo Migration Tools — Business Data Analyst

Application de démonstration développée dans le cadre de la mission 
de migration Akeneo PaaS → SaaS.

## Cas de figures couverts

- Audit du modèle de données As-Is
- Détection des écarts de migration PaaS vs SaaS  
- Rapport qualité et completeness par famille
- Rapport Product Owner avec export CSV daté

## Stack technique

Python · Streamlit · pandas · json
